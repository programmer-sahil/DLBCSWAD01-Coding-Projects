# Task 3 — CSS3 Concepts Demonstration

A dependency-free HTML/CSS project demonstrating the practical requirements of Task 3:

- CSS selectors and declaration blocks
- External stylesheet through `<link rel="stylesheet" href="styles.css">`
- Internal CSS through a `<style>` element
- Text alignment and background colours
- Reusable class selectors
- CSS comments
- Margin, padding and border differences
- A styled `<div>` using the `.menu-card` class
- Responsive behaviour and reduced-motion support

## Run the project

1. Download or clone the repository.
2. Open `index.html` directly in a current browser.
3. Resize the browser and inspect the page using browser developer tools.
4. Upload `styles.css` to the W3C CSS Validation Service for validation.
